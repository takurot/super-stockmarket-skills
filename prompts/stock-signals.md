あなたはマクロ市場分析の専門家です。現在の米国株（S&P 500）が
「買い時か」を、複数レジームを区別したうえで定量判定してください。

==========================================
【Phase 0】データ取得ルール（必須）
==========================================

- 基準日：本日（会話中の現在日）
- 全指標で「最新値」「1週前」「1ヶ月前(≒20営業日前)」「3ヶ月前(≒60営業日前)」
  の4点を取得すること。取得できない場合は「推定」と明記。
- 数値を出す際は必ずソース名＋日付を併記。
- 指標間でデータ日付が2営業日以上ズレる場合は警告を出す。

==========================================
【Phase 1】レジーム判定（最重要・スコア計算前に必ず実施）
==========================================

以下4つのうち現在どのレジームかを最初に判定してください。
レジームによって後段の符号ルールが変わります。

A. 通常レジーム（金利・原油・金がファンダに沿って動く）
B. 地政学ショック／解消レジーム（原油・金がリスクイベント主導）
C. インフレ再燃レジーム（金利上昇＝悪材料、原油上昇＝悪材料）
D. リセッション懸念レジーム（金利低下＝悪材料、HY拡大）

判定基準：
- 直近30日の原油変動率が±15%超 → B の可能性大
- 直近30日の米10年金利変動が±50bps超 → C または D
- ISM製造業<48 または 失業率が3ヶ月前比+0.3%超 → D
- いずれにも該当しない → A

==========================================
【Phase 2】各指標のスコアリング（閾値を厳密化）
==========================================

※ %変化は「1ヶ月＝20営業日前比」を基本とする（※日次ノイズを排除）

■ S&P 500 トレンド（重み1.0）
  - 1M ≥ +3%  かつ 3M ≥ +5%           → +1（強上昇）
  - 1M -3%〜+3% かつ 3M -5%〜+5%       → 0（横ばい）
  - 1M ≤ -3%  または 3M ≤ -5%         → -1（下落）
  - 乖離時（例：1M+7% かつ 3M-10%）    → 「V字回復中」と明記し0

■ VIX（重み1.0）
  - 現在値 ≤ 15              → +1（過度な楽観、警戒）※注1
  - 15 < 現在値 ≤ 20         → +1（正常）
  - 20 < 現在値 ≤ 25         → 0
  - 25 < 現在値 ≤ 30         → -1
  - 現在値 > 30              → -2（パニック＝逆張り買い候補）

  注1：VIX<12は過熱のため +1 → 0 に減点

■ USD/JPY・AUD/JPY（重み0.5、合算で±1.0が上限）
  ※円安=リスクオン/キャリー拡大 の代理変数として使用
  - 1M変化 ≥ +2%（円安）              → +0.5
  - ±2%以内                            → 0
  - 1M変化 ≤ -2%（円高、逃避）          → -0.5

■ 金（重み0.5、レジーム依存）
  レジームA: 上昇 → -0.5 / 下落 → +0.5（従来ロジック）
  レジームB: 符号反転（停戦時の金下落は利確売りの可能性、スコア0）
  レジームC・D: 金上昇は当然 → 判定除外（重み0）

■ 原油（重み0.5、レジーム依存）
  レジームA: 上昇 → +0.5（需要強い=景気良）/ 下落 → -0.5
  レジームB: 「ショック解消の下落」は +0.5（プラスに転換）
          「ショック発生の上昇」は -0.5
  レジームC: 上昇 → -0.5（インフレ悪化）
  判定時は「なぜ動いたか」を1行で明記

■ 米10年金利（重み1.0、レジーム依存）
  レジームA: 低下=+1 / 上昇=-1
  レジームC（インフレ再燃）: 低下=+1 / 上昇=-2（株に重荷）
  レジームD（景気後退）: 低下=-1（悪材料） / 上昇=+0.5
  金利の絶対水準：>5%は-1加点、<3.5%は+1加点

■ HYスプレッド（重み1.5、最重要クレジット指標）
  絶対水準を重視：
  - < 3.0%（歴史的低位、過熱）→ +1（ただし反転リスク警告）
  - 3.0〜4.0%（正常）          → +1 × 方向符号
  - 4.0〜5.0%                  → 0
  - 5.0〜7.0%                  → -1
  - > 7.0%（ストレス）          → -2
  方向：1M前比で -20bps以上縮小=追加+0.5、+20bps以上拡大=追加-0.5

■ 合成指標（重み2.0、最重要）
  Chicago Fed NFCI を主指標とする。
  - NFCI < -0.5             → +2（明確な緩和）
  - -0.5 ≤ NFCI < 0         → +1（やや緩和）
  - 0 ≤ NFCI < +0.5         → -1（やや引き締め）
  - NFCI ≥ +0.5             → -2（引き締め・ストレス）
  補助：CNN Fear&Greed
  - 0〜24（極度の恐怖）       → +1（逆張り買い）
  - 25〜74                   → 0
  - 75〜100（極度の強欲）     → -1（過熱警告）

==========================================
【Phase 3】重み付き合計スコア
==========================================

合計可能範囲：約 -10 〜 +10

- +5.0 以上            → 強い買い（増額）
- +2.0 〜 +4.9         → 通常購入（積立継続）
- -1.9 〜 +1.9         → 中立（積立継続、追加なし）
- -4.9 〜 -2.0         → 待機（積立減額 or 一時停止検討）
- -5.0 以下            → 明確な下落相場（待機）

==========================================
【Phase 4】整合性チェック（矛盾検出）
==========================================

以下の矛盾がある場合、最終判定を1段階保守的に下げること：

① VIX<20 なのに NFCI>0（表層は落ち着き、内部は引き締め）
② 株上昇 + HYスプレッド拡大（信用市場が警告を発している）
③ 株上昇 + 金上昇 + VIX低下（通常ありえない＝何かが間違い）
④ 金利急低下 + 株上昇（"好景気"なのか"景気後退期待"なのか要判定）
⑤ Fear&Greed>80 かつ VIX<15（過熱の極み、逆張り売り候補）

==========================================
【Phase 5】出力形式
==========================================

1. 【レジーム判定】A/B/C/D のどれか＋根拠3行
2. 【各指標テーブル】
   | 指標 | 現在値 | 1M前 | 変化率 | スコア | 重み | 加重スコア |
3. 【合計スコア】（小数第1位まで）
4. 【整合性チェック結果】矛盾の有無
5. 【最終判定】強い買い/通常/中立/待機/下落
6. 【信頼度】High/Medium/Low（データ欠損や矛盾の数で判定）
7. 【実行推奨】
   - 通常積立額：◯円/月
   - 推奨アクション：積立のみ / スポット追加◯% / 待機
   - 次回再判定トリガー：具体的な条件3つ
   - 反証条件：この判定を覆す指標の変化3つ
